# Third-party skills in this folder

Downloaded from GitHub on 2026-11-06 and checked before adding: SKILL.md files and scripts were read for
network calls, credential use, hooks and instructions that would override the user. Nothing here installs
itself or runs on its own; scripts only run when a skill is used. Each folder keeps its upstream licence.

| Skill(s) | Source | Licence | What it helps with |
|---|---|---|---|
| pixelfx | patch-gg/pixelfx | MIT | 244 code pixel-art effects (already used by the game) |
| algorithmic-art, canvas-design, frontend-design, theme-factory, webapp-testing, slack-gif-creator | anthropics/skills | Apache-2.0 | generative art, visual composition, UI design direction, themes, Playwright testing, short looping animations |
| cast, paint, `_jutsu` (shared modules: motion-principles, canvas-generative, design-audit, mobile-principles, ui-ux-pro-max …) | AThevon/genjutsu | MIT | motion design and micro-interactions, art direction, design audits |
| juice-principles, juice-scan, juice-apply | m4bwav/game-juice | MIT | game feel: hit-stop, shake, squash and stretch, audits of a game's juice |
| game-feel, create-game-assets, game-ui-ux, performance-optimization, procedural-gen, camera-systems, audio-design, roguelike, rpg | gamedev-skills/awesome-gamedev-agent-skills | Apache-2.0 | game design and engineering know-how for this kind of game |
| codixel | mankidev/codixel | MIT | pixel-art sprites, rigs and animation (demo images left out) |
| pixel-art-studio | Gamezxz/pixel-art-studio | MIT | hand-placed pixel art with Python/Pillow, palette cleanup |
| reanimate | NiazMorshed2007/reanimate | MIT | rebuild an animation from a reference frame by frame |
| hallmark | Nutlope/hallmark | MIT | design that does not look generated (its optional edit hook is NOT installed) |
| unslop | heydamir/unslop | CC-BY-4.0 (by heydamir) | turning generic-looking UI into a designed one |
| color-expert | meodai/skill.color-expert | CC-BY-4.0 (by meodai / David Aerne) | colour theory, palettes and ramps |
| caveman, investigate-first, surgical-patch, verify-and-stop | JuliusBrussee/caveman | see each LICENSE | terse "caveman mode" to save tokens (only when asked), focused debugging and small fixes |
| paleo, paleo-summary, paleo-trim-context, paleo-budget | mocasus/paleo | MIT | token saving: summarising long output, trimming context, token budgets (only when asked) |
| systematic-debugging, verification-before-completion | obra/superpowers | MIT | root-cause debugging, proving work before calling it done |

Left out on purpose: caveman-compress (sends file contents to an outside AI API), paleo-auto (switches to
terse replies on its own), sprite-gen (needs paid image APIs), and skills for engines this game does not use.
