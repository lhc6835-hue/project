# AETHER HEART (에테르 하트) — 기획서 v0.1

> 정령을 키우고, 몸에 받아들이고, 던전으로 뛰어든다.

- 장르: **정령 육성(방치/키우기) + 로그라이트 던전 런 (층별 웨이브)**
- 플랫폼: 웹 브라우저 (모바일 터치 + PC 키보드/마우스)
- 그래픽: 2D 픽셀 아트, 내부 해상도 480×270, 정수 배율 확대
- 타이틀은 가칭. 후보: **AETHER HEART / 에테르 하트**(기본), 정령결(精靈結), ELEMENTA GARDEN

---

## 1. 한 줄 요약과 핵심 재미

정원에서 내 정령을 키운다 → 출격하면 정령이 내 몸에 흡수되어 그 정령의 힘으로 싸운다 → 던전을 깊이 내려갈수록 보상이
커지고, 죽거나 귀환하면 얻은 재화로 정령이 영구적으로 성장한다 → 성장 단계가 오르면 평타·스킬·포즈·이펙트가 통째로 바뀐다.

핵심 재미 세 가지:
1. **눈에 보이는 성장**: 새싹 → 성체 → 각성. 단계마다 싸우는 방식과 모습이 확 달라진다.
2. **한 판의 변주**: 층마다 고르는 강화 카드로 같은 정령도 매번 다르게 굴러간다.
3. **수집**: 진행하다 열리는 정령 뽑기로 등급별 정령을 모으고, 고유 패시브로 조합한다.

## 2. 왜 이 장르 조합인가 (웨이브 생존 대신 "정원 + 던전 런")

- 아레나 웨이브 생존은 물량 처리 위주라 **정령마다 다른 평타·스킬의 손맛**이 묻힌다.
- 층 단위 던전 런은 한 층 = 웨이브 2~3개 + 보상 선택으로 끊겨서, **스킬을 직접 쓰는 액션**과
  **짧은 판(5~12분)**, **판 사이의 키우기**가 자연스럽게 맞물린다. 모바일에서 끊어 하기도 좋다.
- 웨이브의 긴장감은 그대로 살린다: 각 층의 방은 문이 잠기고 웨이브를 다 깨야 열린다.

## 3. 엔진과 기술 선택

**웹 (TypeScript + Vite + Canvas 2D 자체 렌더러)** 로 만든다. Unity/Godot 대신 이걸 고른 이유:

| 기준 | 웹 (선택) | Godot / Unity |
|---|---|---|
| PixelFX 이펙트 | 원본 JS 코드를 **실시간으로** 그대로 실행 → 속성별 색 바꾸기, 단계별 화려함 조절, 좌우 반전, 시드 변주를 런타임에 | 스프라이트 시트로 구워야 함 → 색·크기 변주마다 시트가 늘어남 |
| 품질 검증 | 제가 브라우저로 직접 실행·스크린샷·영상 확인하며 다듬을 수 있음 | 에디터를 제가 띄울 수 없어 눈으로 확인하며 다듬기 어려움 |
| 모바일+PC 동시 지원 | 링크 하나로 폰·태블릿·PC 바로 실행 | 웹 빌드는 무겁고 모바일 브라우저 호환이 약함 |
| 배포 | Cloudflare Pages에 올려 주소로 바로 플레이 (이 세션에 Cloudflare가 연결돼 있음) | 빌드·스토어 과정 필요 |

- 렌더링: 480×270 RGBA 프레임 버퍼에 PixelFX 방식(색 버퍼 + 빛 버퍼)으로 그리고 합성, `image-rendering: pixelated` 확대.
- 캐릭터 리그는 각 파츠를 픽셀 단위로 회전 래스터라이즈(최근접 샘플링 + 외곽선 보정)해서 회전해도 픽셀 아트 느낌이 유지되게 한다.
- 저장: 브라우저 localStorage (자동 저장, 내보내기/불러오기 코드 제공).
- 오디오: Web Audio로 간단한 효과음 합성 (2차 목표).

## 4. 게임 루프

```
[타이틀] → [정령 정원(허브)] ──출격──▶ [흡수 연출] → [던전 1층 … 10층] ──사망/귀환/클리어──▶ [결산] → [정원]
                ▲                                                                                    │
                └──────────── 정수·정령석으로 레벨업 / 진화 / 시설 강화 / 뽑기 ◀───────────────────────┘
```

- 한 판: 10층. 층마다 방 1개(웨이브 2~3) → 보상 선택 → 다음 층. 5층 중간 보스, 10층 최종 보스.
- 층 사이에 **귀환** 가능(지금까지 얻은 재화 100% 보존). 사망 시 70%만 보존. → 더 내려갈지 고민하게 만듦.
- 10층 클리어 시 다음 **심도**(난이도 단계) 해금. 심도마다 적 강화 + 보상 증가.

## 5. 정령 시스템

### 5.1 속성 4종과 상성

| 속성 | 색 | 성격 | 강함 → 약함 |
|---|---|---|---|
| 불 | 주황·빨강 | 높은 공격, 지속 화상 | 불 → 바람 |
| 바람 (폭풍) | 연두·하늘·전기 | 빠른 공속, 이동, 연쇄 | 바람 → 땅 |
| 땅 | 갈색·호박 | 높은 체력, 넉백, 방어막 | 땅 → 물 |
| 물 (얼음) | 파랑·하양 | 둔화·빙결, 회복 | 물 → 불 |

상성 우위 공격: 피해 +30%. 적에게도 속성이 있다 (층마다 다른 속성 비중).

시작할 때 4개 중 하나를 고른다(선택 화면에서 각 정령이 대기 모션으로 떠 있고, 고르면 짧은 시연 공격).

### 5.2 성장

- **레벨**: 1~30. 정원에서 정수를 먹여 올린다. 레벨마다 공격·체력 상승.
- **성장 단계** 3단계:

| 단계 | 조건 | 변화 |
|---|---|---|
| 1 새싹 | 시작 | 평타 + 스킬 1 |
| 2 성체 | Lv10 + 진화석 | 새 평타 + 스킬 2개 (이전 스킬은 강화형으로 교체), 새 포즈·모션, 외형 변화 |
| 3 각성 | Lv25 + 각성석 + 보스 처치 1회 | 새 평타 + 스킬 2개 + **궁극기**, 부유 포즈, 상시 오라 |

- 진화 연출: 정원에서 정령이 알/고치 형태로 빛나다 터지며 새 모습으로 등장 (spawn/egg-hatch, holy/sunburst, ui/level-up).

### 5.3 정령 등급 (뽑기)

| 등급 | 확률 | 특징 |
|---|---|---|
| ★ 일반 | 60% | 기본 스탯, 패시브 1 |
| ★★ 희귀 | 30% | 스탯 +15%, 패시브 1 (더 강함), 색 변주 |
| ★★★ 영웅 | 8.5% | 스탯 +35%, 패시브 2, 고유 색 + 외형 장식 |
| ★★★★ 전설 | 1.5% | 스탯 +60%, 패시브 2 + 고유 효과, **빛·어둠 전설 정령** 포함 |

- 같은 속성이면 평타·스킬 세트는 공유하고(작업량 관리), 등급은 스탯·패시브·색·장식·이펙트 강도로 차별화.
- 전설 빛 정령 / 어둠 정령은 고유 스킬 세트 (holy, shadow 계열 이펙트) — 2차 업데이트 범위.
- 중복: 정령 조각으로 변환 → 같은 정령 "돌파"(최대 레벨 +5, 최대 3회).
- 천장: 60회 안에 전설 확정. 10연차 시 희귀 이상 1개 확정.
- **실제 결제 없음.** 뽑기 재화(정령석)는 게임 플레이로만 얻는다.
- 해금: **5층 중간 보스 첫 처치** 시 정원에 "소환의 샘"이 생기며 튜토리얼 무료 10연차 지급.

### 5.4 편성

- 출격할 때 **주 정령 1** (몸에 흡수, 평타·스킬 제공) + 2단계 이상 해금 시 **보조 정령 1** (패시브만 제공).

## 6. 흡수 연출 (전투 돌입)

1. 정원 출격 버튼 → 캐릭터가 출격 포탈 앞에 선다.
2. 정령이 캐릭터 주위를 한 바퀴 돌며 속성 입자를 흘린다.
3. 빛의 띠를 남기며 가슴(몸통 중앙)으로 빨려 들어간다 → 하얀 섬광 1~2프레임, 화면 살짝 흔들림.
4. 몸통 중앙에 속성 코어가 켜지고 단계별 외형이 입혀진다:
   - 새싹: 몸통 코어 + 손에 작은 속성 불씨
   - 성체: 코어 + 팔·다리에 속성 문양 띠 + 걸을 때 발자국 입자
   - 각성: 전신 색 변환 + 머리 위 속성 관(불꽃 머리/물 왕관/바람 고리/돌 뿔) + 상시 오라 루프
5. 화면 전환(transitions/iris 또는 속성색 diamond-wipe) → 1층.

## 7. 캐릭터 리그

참고 이미지처럼 **머리, 몸통, 왼팔, 오른팔, 왼다리, 오른다리 6파츠가 완전히 분리**된 블록형 인형. 비율은 독자 디자인으로 잡는다.

- 기본 크기(픽셀): 머리 10×9(모서리 둥글게), 몸통 12×11, 팔 5×11, 다리 6×10 → 전체 약 30px 키.
- 관절 피벗: 목(머리 아래 중앙), 어깨(팔 위쪽 중앙), 엉덩이(다리 위쪽 중앙), 몸통 중심(허리).
- 각 파츠는 각도 + 오프셋(x, y)로 포즈를 표현. 몸통 기울기는 하위 파츠 전체에 전달(계층 구조).
- 키프레임 포즈를 보간(easing)해서 애니메이션. 평타/스킬마다 **예비 동작 → 발사 프레임 → 경직(히트스톱) → 회복** 4구간 (PixelFX act 방식).
- 3/4 시점: 먼 쪽 팔·다리는 한 단계 어둡게 그리고 몸 뒤에 배치.
- 적과 보스도 같은 리그를 크기·파츠 모양만 바꿔 재사용 (예: 돌 골렘 보스 = 큰 사각 파츠).

### 7.1 단계별 대기·이동 포즈 (속성 공통 골격 + 속성별 양념)

| 단계 | 대기 | 이동 |
|---|---|---|
| 새싹 | 가볍게 숨쉬기(몸통 위아래 1px), 팔 자연스럽게 흔들, 가끔 두리번 | 종종걸음: 보폭 작고 팔 흔들림 큼 |
| 성체 | 전투 자세: 한 발 앞으로, 앞팔 들어 올림, 무게 이동 | 달리기: 몸 앞으로 10° 기울임, 팔 크게 교차, 발자국 입자 |
| 각성 | 공중 부유(2~3px 떠서 천천히 오르내림), 팔 살짝 벌림, 오라 | 활공: 다리 모으고 몸 20° 기울여 미끄러지듯, 뒤로 잔상과 속성 꼬리 |

속성 양념: 불 = 몸이 들썩이고 손에서 불씨, 물 = 흐르듯 부드러운 보간, 바람 = 빠르고 가벼운 템포·스카프처럼 펄럭이는 입자,
땅 = 묵직한 착지(이동 중 한 걸음마다 1px 화면 흔들림·먼지).

## 8. 전투

### 8.1 조작

| | 모바일 | PC |
|---|---|---|
| 이동 | 왼쪽 가상 조이스틱 | WASD / 방향키 |
| 평타 | 자동 (가까운 적 자동 조준, 사거리 안일 때) — 설정에서 수동 전환 | 자동 / 마우스 왼클릭 |
| 스킬 1·2·궁극기 | 오른쪽 버튼 3개 (쿨타임 원형 표시) | Q / E / R |
| 회피 대시 | 오른쪽 작은 버튼 | Space |

- 시점: 탑다운 3/4 (벨트 액션처럼 위아래로도 이동). 방 크기는 화면 1~1.5배, 카메라 추적.
- 피격감: 히트스톱(0.05~0.15초), 넉백, 하얀 피격 플래시, 데미지 숫자, 치명타 숫자 별도.

### 8.2 평타 원칙

평타는 **범위 넓은 근거리** 또는 **사거리 짧은 원거리**로만 구성. 단계가 오를수록 범위·타수·이펙트가 커진다.

### 8.3 속성별 · 단계별 기술표 (괄호는 사용할 PixelFX 이펙트, 속성색으로 재색칠)

**불**
| 단계 | 평타 | 스킬 |
|---|---|---|
| 새싹 | 불꽃 할퀴기: 앞쪽 부채꼴 120° 근거리 2연타 (melee/claw-swipe, impacts/hit-spark) | 불씨탄: 짧은 사거리 화염구, 착탄 시 작은 폭발 (fire/fireball, explosions/small-explosion) |
| 성체 | 화염 회전베기: 주변 원형 근거리 (melee/spin-slash) | 화염 고리: 발밑에서 퍼지는 불 고리 (fire/fire-ring) · 화염 숨결: 전방 원뿔 지속 (fire/fire-breath) |
| 각성 | 업화 강타: 넓은 부채꼴 + 폭발 (melee/heavy-cleave, explosions/big-explosion) | 불기둥 (fire/flame-pillar) · 화염 회오리: 따라다니며 끌어당김 (fire/fire-tornado) · **궁극기 운석 낙하** (fire/meteor) |

**물**
| 단계 | 평타 | 스킬 |
|---|---|---|
| 새싹 | 물방울탄: 짧은 사거리 3발 산탄 (water/water-orb, water/splash) | 물보라: 주변 밀쳐내기 + 둔화 (water/splash, water/ripples) |
| 성체 | 물채찍: 전방 넓은 휘두르기 (melee/whip-crack) | 물줄기: 전방 관통 빔 (water/water-jet) · 소용돌이: 적을 모으는 장판 (water/whirlpool) |
| 각성 | 해일 내려치기: 전방 파도 (water/wave-crash) | 간헐천: 연속 솟구침 (water/geyser) · 얼음창: 관통 + 빙결 (ice/ice-lance, status/frozen) · **궁극기 절대영도** (ice/frost-nova, ice/blizzard-vortex) |

**바람 (폭풍)**
| 단계 | 평타 | 스킬 |
|---|---|---|
| 새싹 | 바람 칼날: 앞쪽 넓은 베기, 공속 빠름 (melee/sword-slash) | 질풍 돌진: 경로상 적 베기 (moves/dash-strike 참고, impacts/hit-flash) |
| 성체 | 난도질: 전방 4연타 (melee/dagger-flurry) | 회오리: 앞으로 나아가는 토네이도 (nature/tornado) · 연쇄 번개 (lightning/chain-lightning) |
| 각성 | 폭풍 회전: 원형 + 전기 아크 (melee/spin-slash, lightning/spark-arc) | 낙뢰 (lightning/lightning-strike) · 구전: 주위를 도는 번개 구체 (lightning/ball-lightning) · **궁극기 뇌우** (lightning/storm-cloud, lightning/thunderclap) |

**땅**
| 단계 | 평타 | 스킬 |
|---|---|---|
| 새싹 | 바위 주먹: 짧고 넓은 전방 강타, 넉백 (melee/uppercut, impacts/blunt-hit) | 돌 던지기: 짧은 포물선 (nature/boulder) |
| 성체 | 대지 망치: 전방 내려찍기 + 충격파 (melee/hammer-smash) | 가시 솟음: 전방 일직선 (nature/earth-spike) · 뿌리 속박 (nature/root-snare) |
| 각성 | 지진 내려찍기: 원형 충격파 (impacts/ground-slam) | 가시 지대 (nature/thorns) · 지진: 화면 흔들림 + 넓은 피해 (nature/quake) · **궁극기 대지 붕괴** (moves/ground-pound 참고, explosions/dirt-explosion) |

### 8.4 단계별 이펙트 화려함 규칙

같은 이펙트도 단계가 오를수록:
- 크기 1.0 → 1.4 → 1.9배, 입자 수 ×1 → ×1.6 → ×2.5
- 빛(glow) 세기 0.3 → 0.6 → 1.0, 팔레트 단계 수 증가(새싹 3색 → 각성 5색 + 흰 핵)
- 보조 이펙트 추가: 성체 = 잔불·파편, 각성 = 충격 프레임(impacts/impact-frame) + 화면 흔들림 + 짧은 화면 플래시
- 궁극기: 화면 어둡게 → 캐릭터 컷인(픽셀 아트 클로즈업) → 발동

### 8.5 적

- 일반 적: PixelFX 생물(critters) 기반 — 슬라임, 박쥐, 떠다니는 해골, 유령, 눈알, 뱀, 도깨비불 + 리그 기반 블록 병사.
- 적 속성: 층 테마별(불의 층·물의 층 등)로 비중 변화. 정예 적은 속성 오라 + 체력바.
- 보스 (리그 재사용, 대형):
  - 5층 중간 보스 **돌 거인**: 내려찍기, 돌 투척, 가시 장판.
  - 10층 최종 보스 **공허의 정령사**: 4속성을 번갈아 사용, 페이즈 3개, 쉐도우 계열 이펙트.

## 9. 런 안의 강화 (층 보상)

웨이브 클리어 후 카드 3장 중 1장 선택. 카드 등급(일반/희귀/영웅). 예시:
- 평타 범위 +20% / 평타 2타째에 작은 폭발 / 스킬 쿨타임 -15%
- 상성 우위 피해 +25% / 처치 시 체력 2% 회복 / 대시 후 1초간 공격력 +30%
- 속성 전용: (불) 화상 중첩 3 → 폭발, (물) 빙결된 적 피해 +40%, (바람) 연쇄 +1, (땅) 방어막 생성
- 저주 카드(드물게): 적 강화 대신 보상 ×2

층 보상 방 종류: 전투(기본), 정예(카드 등급↑), 상점(런 전용 코인), 샘(회복), 보물(정령석).

## 10. 정령 정원 (허브, 키우기)

- 정원에 보유한 정령들이 돌아다님 (각자 대기·이동 모션). 탭하면 반응 + 정보.
- **정수의 나무**: 시간이 지나면 정수가 쌓임 (오프라인 최대 8시간). 보유 정령 수·등급에 비례.
- 시설 (정수/코인으로 강화):
  - 정수의 나무: 생산량↑
  - 수련장: 정령 레벨업 비용↓
  - 소환의 샘 (5층 보스 후 해금): 뽑기
  - 유물 제단: 영구 패시브 (시작 체력, 귀환 보상 등)
- 일일 목표 3개 (정령석 보상).

## 11. 재화

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|

## 13. 아트 방향

- 배경: 어두운 톤의 던전 타일 + 층 테마별 색(불 = 붉은 동굴, 물 = 빙결 수로, 바람 = 폭풍 첨탑, 땅 = 수정 광산).
- 캐릭터 팔레트: 중립 회색 몸(참고 이미지 느낌) + 흡수한 정령 속성색으로 문양·코어.
- 이펙트: 단색 덩어리 대신 단계 있는 팔레트 램프 + 빛 버퍼 가산 합성. 어두운 배경 위에서 빛이 살게.
- UI: 픽셀 폰트(한글 지원 비트맵 폰트 — 오픈 라이선스 폰트 사용), 테두리 9-슬라이스 패널.
- 특정 기존 게임의 캐릭터·로고·스프라이트는 따라 그리지 않는다. 블록형 캐릭터도 비율·얼굴·디테일은 독자 디자인.
